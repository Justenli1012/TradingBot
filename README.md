# TradingBot
This is my repository for my personal side project to use a trading to automate my day trading strategy.

Windows Setup:
python -m venv .venv
.venv\Scripts\activate
python -m pip install --upgrade pip
pip install -r requirements.txt

MacOS/Linux Setup:
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
pip install -r requirements.txt
